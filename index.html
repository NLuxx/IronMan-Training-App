Workout guide

Every session type in the plan, explained. The golden rule runs through all of them: easy days genuinely easy, hard days hard. Nearly every mistake in a plan like this is going too hard on the easy days, not too easy on the hard ones. Zones are set by heart rate — pace is whatever those zones give you on the day.
☀️ Two-a-days: morning vs afternoon
On double days the app tags each session AM or PM. The rule behind it: do the session that matters most for that day first, while you're freshest. The tired second slot is for the piece that can absorb some fatigue.
Swim + lift
Swim first, lift later (4+ hours if you can). Lifting beforehand tires the shoulders and lats that hold your stroke together — and technique is the first thing to go. One block only? Swim, then lift.
Swim + easy run
Swim AM while your stroke is sharp; the easy run fills the afternoon.
Swim + quality or long run
Run first — the harder run is the more injury-sensitive session, so it gets the fresh legs. The swim goes later; water is gentle on tired legs.
Run or ride + leg lift
Run/ride in the morning, lift in the afternoon (6+ hours if you can) — lifting first blunts the session more than the reverse. One block only? Run, then lift. Upper-body days barely touch the legs, so order matters little.
Anything + streak jog
The real session takes priority and the daylight; the 2 km streak jog is just circulation — slot it anytime, even late evening.
Three sessions in a day
Biggest piece AM, next around midday, lowest priority last. If recovery is flat, the lift is the first thing to drop.
Brick (ride → run)
The exception to everything: never split these. The run goes straight off the bike, under 5 minutes' transition. Training your legs to run on cycling-fatigue is the entire purpose.
If you can only train once that day
Do the AM (priority) session and move the lower-priority one to a rest slot in the week, or drop it. Never sacrifice the long ride, long run, or a quality session to fit in a streak jog or an upper-gym day.
